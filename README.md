# Rétor

Entrenador de comunicación en el navegador: graba o sube un vídeo (ES/EN/FR) y analiza voz, ritmo, comunicación no verbal y mensaje. Todo el análisis corre en el dispositivo.

- `index.html`: la app completa.
- `kb.json`: técnicas nuevas que la app incorpora al abrirse (array de `{c,t,d,s,e,url}`).

Librerías: MediaPipe Tasks Vision, transformers.js (Whisper), WebLLM (opcional).
